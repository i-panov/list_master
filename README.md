# ListMaster

React-приложение для работы со списком данных с функцией поиска.

## Технологии

- React 16
- Blueprint.js (UI-компоненты)
- Create React App

## Функциональность

- Отображение данных в таблице
- Поиск по содержимому (фильтрация списка)
- Добавление новых элементов

## Запуск

```bash
# Установка зависимостей
yarn install

# Запуск в режиме разработки
yarn start

# Сборка для продакшена
yarn build

# Запуск тестов
yarn test
```

## Структура проекта

```
src/
  App.js       - основной компонент приложения
  App.css      - стили приложения
  App.test.js  - тесты
  index.js     - точка входа
public/        - статические файлы
```
